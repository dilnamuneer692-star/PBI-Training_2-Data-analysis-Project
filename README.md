# PBI-Training_2-Data-analysis-Project

## 📊 Project Overview
This project focuses on **Sales Data Analysis using Microsoft Power BI**. The objective is to analyze sales data, identify useful patterns, and present meaningful information through data visualizations and an interactive dashboard.

This project is part of my Power BI training and helps me develop practical data analytics skills.

## 🎯 Project Objectives
- Analyze sales data to understand business performance.
- Identify trends and patterns in the dataset.
- Compare sales performance across available categories and periods.
- Transform raw data into meaningful information.
- Support data-driven business decisions through visualization.

## 🛠️ Tools & Technologies
- **Microsoft Power BI** – Data analysis and dashboard development
- **Power Query** – Data cleaning and transformation
- **DAX** – Data calculations and measures, if used

## 🔄 Data Analysis Process
1. **Data Import:** Import the dataset into Power BI.
2. **Data Cleaning:** Check missing values, duplicates, and data quality.
3. **Data Transformation:** Prepare the data using Power Query.
4. **Data Modeling:** Establish relationships between tables, where required.
5. **Data Analysis:** Analyze sales data and calculate relevant metrics.
6. **Data Visualization:** Create charts, graphs, and dashboard visuals.
7. **Insights:** Interpret the results and identify meaningful findings.

## 📈 Key Analysis Areas
- Total Sales Analysis
- Product or Category-wise Sales Analysis
- Sales Trend Analysis
- Sales Performance Comparison
- Identification of Important Business Patterns

*The actual analysis areas depend on the columns and visuals available in the dataset.*
